# 📇 ContactHub — Assignment 9

A modern and responsive contact management web application built as **Assignment 9**, focused on practicing CRUD (Create, Read, Update, Delete) operations using JavaScript.

ContactHub allows users to manage their contacts, search for specific people, organize favorites, and quickly connect through phone calls or email.

## ✨ Features

- **Add Contacts:** Add new contacts with essential information.
- **View Contacts:** Display saved contacts in a clean, organized interface.
- **Edit Contacts:** Update existing contact information.
- **Delete Contacts:** Remove contacts with a confirmation alert.
- **Search Contacts:** Search by name, phone number, or email address.
- **Favorites:** Add or remove contacts from the favorites list.
- **Quick Actions:** Call contacts using `tel:` links or send emails using `mailto:` links.
- **Form Validation:** Validate user input before saving contact information.
- **Persistent Storage:** Store contacts in `LocalStorage` so data remains available after page reloads.
- **Interactive Alerts:** Use SweetAlert2 for success messages and delete confirmations.
- **Responsive Design:** Provide a user-friendly experience across different screen sizes.

## 💾 Data Persistence

ContactHub uses the browser's `LocalStorage` API to save contact information locally. Saved contacts remain available after refreshing the page in the same browser, provided the site's stored data is not cleared.
